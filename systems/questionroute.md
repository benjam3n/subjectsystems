# QuestionRoute

Source standing: Selected source material; see version and limits.

## What the source contributes

Atomic questions, route meanings, sequences, nested chains, regress structures, and user journeys.

## Native distinctions and limits

Typed routes, sequences, chains, and predicted-answer continuations have different meanings. Preserve them when using individual artifacts; a generic question list is not equivalent.
