# SDS

Source standing: Selected source material; see version and limits.

## What the source contributes

Diverse designs, selected examples and aspects, iterations, derived requirements, and feasibility assessment.

## Native distinctions and limits

The README specifies a design methodology. Selecting an entire example does not establish which individual feature was essential. This setup does not establish comparative performance.
