# GOSM

Source standing: Selected source material; see version and limits.

## What the source contributes

Goal relationships, gates, repair procedures, project artifacts, decisions, state, and measured outcomes where available.

## Native distinctions and limits

A produced plan, passed gate, executed activity, and achieved outcome are distinct. Historical and current versions may use different contracts; retrieve the version relevant to the case.

These are specified investigative targets or proposed study contributions. A source procedure, stored artifact, study specification and conducted study retain different standing. The [study/system derivation](../research/studies/SUBJECT-STUDY-SYSTEM.md) and [technique contracts](../research/studies/TECHNIQUES.md) determine how the material can enter a custom composition.

|---|---|---|---|

| Goal modification | Which intended outcome or qualification changes during refinement? | A deliberate revised goal with the earlier goal preserved as different where warranted. | No complete technique admitted for this study target |
| Goal achievement condition specification | What must hold for this goal to count as achieved? | Required conditions separated from optional merit and proposed proxies. | No complete technique admitted for this study target |
| Goal achievement status | Do the specified achievement conditions hold in the observed case? | An achievement status with failed and unresolved conditions retained. | M04 |
| Goal means dependence | Which activities contribute to which intended outcomes under what assumptions? | A goal-to-means relation that can be questioned when the claimed contribution fails. | No complete technique admitted for this study target |
| Plan prerequisite | Which conditions must hold before this planned activity can proceed? | Explicit prerequisite conditions, distinguishing necessity from a preferred sequence. | No complete technique admitted for this study target |
| Plan sequence | Which activities must precede which others for the stated plan? | Precedence relations with the dependency that warrants each ordering. | No complete technique admitted for this study target |
| Plan contingency | Which continuation follows from each relevant observed condition? | A stated branch for pass, failure or unresolved evidence in the local plan. | No complete technique admitted for this study target |
| Plan modification | Which part of the plan changes after a decision or observation changes? | A changed plan with unaffected portions retained where their support survives. | No complete technique admitted for this study target |
| Reasoning approach selection | Which analysis variant or method fits the actual situation? | A selected candidate and its context conditions, rather than automatic use of the entire repertoire. | No complete technique admitted for this study target |

| Claim support preservation | Which support remains after an assumption is corrected? | Affected support paths separated from independently supported conclusions. | M05 |
