Identification and repair of consequential operations left unspecified by a system description.

1. Select a concrete input and the result the system must distinguish or produce.
2. Execute the described operations with that input. Mark the first place where proceeding requires inventing an operation, choosing an unsupported criterion, or interpreting an undefined condition.
3. Construct two realizations consistent with the description that differ on the required property. If both fit, the description is insufficient for that property.
4. Supply the missing transformation, interpretation rule, or condition. If it must be performed by a model or a person, state the actual examination they perform and what can correct it.
5. Inspect result consumers. Preserve distinctions such as false, unknown, unavailable, contradictory, and inapplicable wherever they require different actions.
6. Remove components that supply no necessary result, evidence, condition, or useful continuation in the defined use. Retain construction, exploration, and verification steps whose value appears later.
7. Exercise a case that defeated the earlier design. Record the actual difference in result or continuation.
