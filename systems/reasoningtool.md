# Reasoningtool

Source standing: Selected source material; see version and limits.

## What the source contributes

The actual procedures, invocation relationships, and examples. Individual procedures receive their own additional placements.

## Native distinctions and limits

A large procedure collection does not establish correct selection or execution. Retrieve the exact skill when using it; this profile is not a substitute for the original.
