# Local system name

This is an optional development aid. It is not a required per-turn output or a substitute for deriving the operations the actual purpose requires.

Identify the subject, particular purpose, source families and exact source material, and current standing. Choose a name describing the local system's work; the source family can remain in its lineage.

Specify the objects and distinctions required here. Determine which source operations remain suitable, which must change, which are removed, and which new operations are needed. Develop the actual transformations and branches rather than instructing a future model to make the source suitable.

Specify the result and its consumer, the criterion appropriate to it, and a case that would defeat the proposed adequacy claim. Determine what warrants continuation, a changed frame, a new observation, or completion.

Retain actual uses and their scope separately from illustrative examples. The local design has its own identity; preserve the ancestor and the explanation of consequential differences.
