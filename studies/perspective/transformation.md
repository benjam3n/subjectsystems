## Perspective question

| Subject | Question | Target |
|---|---|---|
| Perspective consequence accessibility | When two representations carry equivalent information, which operation or resource difference explains why one makes a consequence available and the other does not? | A finite task with equivalent inputs but an explicitly bounded operation budget. |
| Perspective scope extension | Which preserved relations suffice to transfer one resource-allocation conclusion between a biological and a psychological case? | One sourced case pair with an actual valid inference and a failed transfer caused by a missing premise. |
| Anticipation continuation construction | When does building the next prompt expose a necessary contribution that direct response construction misses? | A live case with retained alternative responses and their different continuations. |
| Anticipation influence attribution | How much of expectation-outcome agreement comes from influencing the outcome rather than forecasting independently? | A design that varies exposure to the expectation while retaining the original expectation record. |
| Uncertainty decision sensitivity | Which unresolved distinction changes the selected next operation rather than only its explanation? | A sensitivity result with a decision that changes at an identified distinction. |
| Resource use avoidable cost | Which apparent inefficiencies disappear when exploration, information or option preservation enters the fixed task standard? | One measured or fully specified comparison with the omitted contribution restored. |
| Deviation effect robustness | Which benefits survive changes in admissible contexts without redefining the objective after seeing the outcome? | An explicit context set with at least one separating failure. |
| Conflict resolution method applicability | When does changing the sequence of access create a genuinely feasible joint improvement? | A live conflict model with evidenced timing, resource and agreement constraints. |
| Subject name substitution effect | Which literal name changes alter inference with the underlying definition held fixed? | A fixed-content comparison that distinguishes wording effects from definition effects. |
| Memory active content interference control | Which source-listed paradigms separate maintenance failure from updating demands and interference control? | A task-specific construct comparison using the original paradigm evidence, beyond the functional branch inventory. |
