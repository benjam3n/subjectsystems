For a fixed bearer, input domain, and consequence measure, R(x, c) denotes the response to input x in context c.

| Change | Description |
|---|---|
| Input change | A different x is supplied to the same response relation. |
| Response change | The observed response differs. |
| Rule change | The relation R changes. |
| State change | The bearer's current state changes. |
| Context change | A condition represented by c changes. |
| Access change | A previously inaccessible input or operation becomes available. |

A thermostat can turn a heater on or off under different temperatures while retaining the same threshold rule.
