## Memory qualification

| Qualification | Logical force | Subject | Consequence |
|---|---|---|---|
| Task relevance | Defines the functional context | Memory active content maintenance; Memory active content update | State which content matters to the task; items, goals and strategies are examples, not three exclusive child subjects. |
| Binding | Possible feature, not universal necessity | Memory active content binding | Investigate whether and how relevant elements are associated in the case; do not require binding as an earlier step for every use. |
| External support | Internal maintenance can occur without external support | Memory active content external support dependence | Compare stated support conditions instead of requiring every task to be externally unsupported. |
| Temporary duration | Frequent, not an invariant lifetime | Memory active content persistence duration | Measure usability over time under stated conditions; do not assume a single expiry time. |
| Interference-related temporariness | Possible causal contribution | Memory active content interference; Memory active content persistence duration | Separate delay from competing material before attributing loss to elapsed time alone. |
