| Type | Description |
|---|---|
| Subject | A specified matter of consideration. |
| Study | An inquiry or construction concerning a specified matter. |
| Study program | Related inquiries developing a subject across questions and cases. |
| Technique | Specified operations acting on declared inputs under stated conditions. |
| System | Contributors connected through interfaces, dependencies, conditions, state, and operations. |

| Relation | Case |
|---|---|
| Subject is investigated by Study | A fixed matter can be investigated by several studies; one study can investigate several distinct matters. |
| Study specification specifies Study execution | A protocol can exist without a run; a run can fail to follow the protocol. |
| Study execution produces Finding | An investigation can yield a counterexample, a construction, an unresolved result or no informative result. |
| Study execution uses Technique | A study applies a method to its particular material. |
| Study execution uses result of Earlier study | A finite coverage finding reveals an unhandled state in the GOSM gate. |
| Study execution investigates Technique | A branch-coverage investigation tests the operation used by an achievement assessment. |
| System organizes Components | Interfaces, order, conditions and state connect participating operations, artifacts or studies. |
| System can be investigated as Subject | The order-dependence of a composition becomes a specified matter. |
| Subject-specific system serves Subject | Several local methods can contribute to one target's required result. |
| Study program coordinates Studies | Several inquiries can contribute to a common unresolved matter. |

## System composition order dependence

Increment then double maps 1 to 4. Double then increment maps 1 to 3.
