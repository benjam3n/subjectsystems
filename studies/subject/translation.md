| Record | Definition | Example |
|---|---|---|
| Discipline entry point | An established way to locate a body of work | Psychology; a JEL or MSC category |
| Subject | A specified matter of consideration | Shape representation rotation duration |
| Case | The parameters fixing one investigation | These stimuli, this agent, these timing endpoints |
| Claim | A possible answer with scope and standing | A stated performance difference under those conditions |
| Technique | A way to investigate or produce a result | A particular matching task or solver portfolio |
| Requirement | A condition for a specified operation, result, quality, or justification | A candidate exists at selection time |
| Program | Coordinated work whose contributions span subjects | Resource retention |

| Dimension | Evidence condition |
|---|---|
| Importance | Consequences for specified beneficiaries, goals, costs, risks, and alternatives |
| Recognition | Defined work under the exact name or verified aliases |
| Attention received | A declared corpus, time period, effort measure and denominator |
| Technique development | Specified methods, requirements, available implementations and limitations |
| Technique success | Results for defined tasks, criteria and comparisons |
| Transfer | Evidence that the result or method remains applicable under specified changes |
| Underrepresentation | A discrepancy between measured effort and a justified priority allocation |
