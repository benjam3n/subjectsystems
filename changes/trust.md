Reliance depends on a source or capability whose contribution is unclear.

Make the relevant source, demonstrated action, and limits of reliance inspectable.

Example: An assistant says a file has been fixed, but provides only an intended edit.

> The edit is proposed. Completion requires the changed file and the relevant verification.

A trustworthy presentation cannot substitute for the claimed action. Do not seek increased trust when reduced reliance is warranted.
