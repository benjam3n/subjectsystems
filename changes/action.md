The desired action is understood, but a removable obstacle still prevents it.

Complete the authorized part or remove the identified obstacle. Return the usable result.

Example: The approved README wording is known, and the user has asked for the file to be updated.

> Apply that wording to README.md and verify the saved contents.

A promise or plan is not completion. Do not infer authorization for a different action.
