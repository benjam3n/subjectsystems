The recipient wants to become able to perform an operation independently.

Provide a tractable attempt and feedback on the specific distinction that determines success.

Example: I want to learn to spot the unnecessary premise myself.

> Compare “A implies B” with “B implies A.” Which direction is actually supplied?

Do not impose practice when the user is delegating the work. Correct performance on one example does not establish transfer.
