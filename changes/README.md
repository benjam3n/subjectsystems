Open repertoire of conditional contributions. The kinds overlap, can combine, and do not exhaust mind change. Subject links identify supporting distinctions, not equivalences between subjects or human and model mechanisms.

| When | Contribution |
|---|---|
| A needed answer is missing. | [Knowledge acquisition](knowledge.md) |
| A consequential difference is present but hard to distinguish. | [Perceptual discrimination](discrimination.md) |
| The answer is available, but its relation to the problem is unclear. | [Understanding formation](understanding.md) |
| Relevant material is available, but something else occupies the current focus. | [Attention redirection](attention.md) |
| An accepted fact is not affecting the decision to which it applies. | [Relevance recognition](relevance.md) |
| The work requires carrying too many dependencies at once. | [Active memory support](load.md) |
| Something previously understood is unavailable at the moment it is needed. | [Memory retrieval](retrieval.md) |
| The recipient wants to become able to perform an operation independently. | [Skill development](skill.md) |
| The strength of commitment does not match the available support. | [Confidence adjustment](confidence.md) |
| Reliance depends on a source or capability whose contribution is unclear. | [Trust calibration](trust.md) |
| The next action depends on what is anticipated to happen. | [Expectation revision](expectation.md) |
| The person wants a change in willingness, interest, or perceived effort. | [Motivation change](motivation.md) |
| The person explicitly wants help with the emotional burden of the current situation. | [Emotional state support](emotion.md) |
| What the person prefers depends on a tradeoff that remains abstract. | [Preference clarification](preference.md) |
| The procedure for choosing is creating avoidable work or concealing a relevant alternative. | [Decision process revision](decision.md) |
| The desired action is understood, but a removable obstacle still prevents it. | [Action enablement](action.md) |
| A familiar response would repeat a known error in the present scope. | [Response inhibition](inhibition.md) |
| The current account may exclude the very change that would make the inquiry useful. | [Possibility discovery](exploration.md) |
| A correction has been acknowledged but has not changed the next applicable conduct. | [Correction uptake](correction.md) |

User-directed designs with constructed examples. Applicability and recipient effects require examination in the actual situation; no universal optimality or empirical effectiveness is established by inclusion.
