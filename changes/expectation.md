The next action depends on what is anticipated to happen.

Make the consequential possible outcome and its corresponding continuation concrete.

Example: A plan assumes the recipient will understand after one explanation.

> If the answer is already understood, use a demonstration or action only if it serves a remaining need.

A possible outcome is not an observed result or an assigned probability.
