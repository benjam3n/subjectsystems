# Subject naming boundary review

Constructed cases examining the new definitions. Distinct requested determinations do not imply disjoint classes of episodes. Aliases are merged, qualified targets are linked to their broader subjects, and unresolved overlaps remain explicit. This is not a complete pairwise exclusion proof.

| First subject | Compared subject | Relation | Separating or shared case | Consequence |
|---|---|---|---|---|
| Reasoning approach selection | Reasoning approach creation | Distinct determinations | Choosing A from an existing set leaves the set unchanged; inventing C enlarges it without choosing C. | Specify the initial candidate set and identity rule; a workflow can do both. |
| Reasoning approach creation | Reasoning approach modification | Context-dependent distinction | Changing A into A2 is modification; A2 can also count as newly created if version identity is the classified target. | Do not declare process classes disjoint. Fix whether the subject asks for a new approach identity or a revised version; otherwise mark the request composite or unresolved. |
| Reasoning approach modification | Reasoning approach comparison | Distinct determinations | A revision can be made without showing any benefit; the unchanged pair can be compared without revising either. | Keep production of the version separate from the verdict about it. |
| Reasoning approach selection | Reasoning approach selection criterion | Distinct determinations | The criterion can change while the chosen approach remains A; the choice can change under one unchanged criterion. | The shared name prefix is not sufficient proof that choosing is a genus of criterion formation. |
| Reasoning approach execution fidelity | Reasoning approach contribution adequacy | Distinct determinations | A faithful execution can produce an irrelevant contribution; a departure can supply the required contribution. | Record what was followed separately from what was accomplished. |
| Reasoning approach applicability | Reasoning approach selection | Distinct determinations | Two approaches satisfy their assumptions while only one is selected under cost constraints. | Applicability removes an objection; it does not uniquely select a method. |
| Reasoning contribution selection | Reasoning approach selection | Distinct determinations | Choose to construct a counterexample, then choose which approach will construct it. | The contribution kind is held fixed only in approach selection. |
| Claim truth conditions | Claim support limits | Distinct determinations | A proposition retains its truth conditions when a supporting source is withdrawn; its warrant changes. | Do not rename support limits as truth boundaries. |
| Claim content specification | Expression representation fidelity | Distinct determinations | Fix what an assertion says, then determine whether a summary preserves it. | Interpretation of the source is input to the fidelity comparison. |
| Claim support sufficiency | Claim acceptance confidence | Distinct determinations | A record expresses high confidence even though its stated grounds do not meet the acceptance threshold. | Reported confidence and warrant require separate evidence. |
| Claim inference validity | Claim inference counterexample | Investigation target versus constructive contribution | A counterexample establishes invalidity, but validity can be assessed without constructing such a case. | Link the contribution to the assessment; do not infer that all validity investigations are counterexample construction. |
| Reasoning assumption consequence derivation | Claim inference consequence | Alias | Both draft definitions produce a consequence from the same premises under the same rules. | Remove the duplicate canonical entry; preserve the alternate name in Name Changes. |
| Question identity | Question answer fit | Distinct determinations | Two wordings can ask the same question while a supplied response answers a different one. | Question identity is fixed before judging that response's fit. |
| Question answer fit | Question answer completeness | Narrower aspect, not exclusive alternatives | A partially responsive answer has some fit while leaving one required distinction unresolved. | Completeness refines the coverage aspect of fit. These must not be claimed as disjoint siblings. |
| Question route specification | Plan contingency | Overlapping general and qualified scopes | An answer-dependent next-step rule is both a question-route rule and a plan contingency. | The qualified route view is not a second independent matter. Record the target specialization; do not choose a home merely by project name. |
| Goal selection | Commitment adoption | Distinct determinations | An agent selects a preferred candidate goal while postponing undertaking it. | Choosing the candidate and establishing the undertaking have different state changes. |
| Goal achievement status | Execution state completion | Distinct determinations | A repository update completes while the goal that corrected understanding affects later work remains unachieved. | Use the specified goal conditions and activity completion conditions separately. |
| Preference hypothesis creation | Criterion justification | Distinct determinations | Observed dislike of a name supports a preference account without proving that everyone should reject that name. | Descriptive favoring is not normative justification. |
| Memory record retrieval | Memory record reconstruction | Different acquisition mechanisms; possible composite | An intact file is located; a missing paragraph is separately reconstructed from surviving versions. | Identify whether the requested result is an existing record or an inferred reconstruction. |
| Memory record status recovery | Memory reuse fidelity | Distinct determinations | A rejected decision is retrieved with its status, then incorrectly used as current. | Recovered status does not establish faithful later use. |
| Discovery contribution novelty | Memory record retrieval | Distinct relations on one episode | Retrieving an old question is new to the current inquiry but preserves an older item's identity. | Novelty and historical recovery are different assertions about the episode, not disjoint event classes. |
| Expression representation creation | Execution record representation | General versus qualified target | Constructing a run record is a form of creating an expression of the run. | Treat the execution-record target as a specialization; do not assert unrelated exclusive branches. |
| Capability use transfer | Understanding use transfer | General versus qualified target | Using a previously grasped relation in a new format is one kind of capability transfer. | The qualified understanding target narrows the capability matter; it does not become an exclusive peer of all capability. |
| Intelligence adaptation transfer | Understanding use transfer | Overlap remains possible | An agent adapts by using a grasped relation in a new task; one performance bears on both scopes. | No exclusive Intelligence/Understanding partition has been established. These are overlapping aspects under Capability until definitions or units change. |
| Learning correction uptake | Memory record retention | Distinct determinations | A stored correction can fail to affect the next applicable action. | Inspect later use rather than certifying learning from storage. |
| Improvement comparison result | Learning change attribution | Distinct determinations | A learned habit can worsen performance; an artifact repair can improve without experiential learning. | Betterment and experience-dependent origin are different relations. |
| System interface compatibility | Resource configuration feasibility | Distinct determinations | A producer and consumer agree on meaning but lack capacity to run jointly; capacity can also be ample while meanings conflict. | Semantic contract compatibility and allocation feasibility vary independently. |
| System interface compatibility | Expression interpretation alignment | Potential specialization; case still required | When a consumer interprets an instruction, interface meaning and recipient interpretation can describe the same mismatch. | Do not certify exclusion for this pair. Derive whether a particular contract mismatch is the same attributed-interpretation matter or a different formal contract relation. |
| Reasoning approach failure diagnosis | Reasoning error location | Distinct determinations with possible dependence | One row locates the invalid step; the other explains which approach feature caused the failure. | A location report is not a causal explanation of that failure. |
| Subject scope exclusion | Subject scope inclusion | Different universal claims | A class can fail to include another while still sharing instances with it. | Not-a-subtype does not entail disjointness. |
