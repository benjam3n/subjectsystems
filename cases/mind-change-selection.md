Worked design cases. The arithmetic and repository changes below are directly inspectable. The other continuations are model judgments on specified situations. They do not establish measured human effects, comparative model reliability, or universal optimality.

| Situation | Selected operation and concrete contribution | Consequence and boundary |
|---|---|---|
| The user repeatedly rejects an explanation because the model treats mind change as belief change. | Change the model's selection rule. Include the person, the model, and their conditions as possible locations of change; make the rule the repository default. The current construction installs that rule in AGENTS.md and supplies its operative description. | A later model is instructed to select the change and method without another technique-selection prompt. Actual future uptake remains to be observed. When a user instead asks for an explanation of a factual error, an evidence-based explanation remains eligible. |
| Two costs are A = 60 + 12n and B = 18n. Repeated prose has obscured their comparison. | Change the representation to A minus B = 60 minus 6n. Equality is at n = 10; A costs less above 10 and B costs less below 10. At n = 9, 10, 11 the differences are 6, 0, -6. | The representation exposes a decision boundary and the nearby values verify the calculation. This demonstrates the mathematical distinction, not a measured change in the reader. If the formula itself is inaccessible to the person, use concrete comparisons instead. |
| A person can interpret a diagram on a large screen but cannot distinguish its labels on the available small display. | Enlarge or recompose the relevant diagram through an available tool. If that cannot be done, supply the essential relations in an accessible representation. | The candidate change concerns location or access to the representation. Repeating the conceptual explanation does not repair the stated visibility condition. If visibility is adequate and the relation is misunderstood, a representation or conceptual operation can be appropriate. |
| Spoken content is inaudible in the current location and an accurate transcript is available. | Provide the transcript now. Compare relocation only if it has a specific advantage worth the disruption and is feasible for the person. | The same information becomes available through changed interaction conditions. In a task that specifically requires hearing the sound, a transcript cannot substitute for adequate listening conditions. A suggested move is not an observed relocation. |
| One necessary fact can be supplied now; the opportunity to use it closes before a long explanation would finish. | Supply the fact first, with any qualification necessary to use it correctly. Provide further material only if it contributes within the remaining opportunity. | Timing and order govern the choice. A necessary prerequisite cannot be removed just to accelerate delivery; if the recipient would otherwise misuse the fact, include that prerequisite. A later follow-up is pending unless a real continuation mechanism exists. |
| Comparing two candidates requires a distinction the recipient has explicitly said they do not understand. | Establish the distinction using the smallest adequate contrast, then make the comparison using it. Recheck the need if the contrast shows the distinction was already available. | The first operation earns its cost through the second. A rule that admits only immediately valuable standalone statements can wrongly remove it. If the distinction is already usable, repeating it adds cost and the comparison can begin directly. |
| The person says the intellectual exploration itself is what they want, and the model keeps assigning implementation tasks. | Preserve the intrinsic aim and perform the next consequential conceptual operation. For this inquiry, distinguish changing a current state from changing which later changes become reachable and selectable. | The goal of exploration need not be justified by immediate action. If the person asks for implementation, that request instead selects executable work. Increasing motivation toward an invented task is not an improvement. |
| The user requests the product of 17 and 19, with no consequential ambiguity. | Return 323. | The task is handled by a direct answer. Running a broad taxonomy, asking for preferred methods, or adding a retention test would create unsupported overhead. If the user asks how to multiply such numbers mentally, showing 17 times (20 minus 1) has a different purpose. |
| The person reports that the new explanation feels clearer, but independent use has not been observed. | Record reported clarity if retention is useful; keep capability and transfer unresolved. Continue with the requested work unless a later decision depends on demonstrating independent use. | The report is evidence about experienced clarity. It is neither proof of transfer nor a reason to disregard the person's experience. Add a suitable task only when the value of that evidence warrants the burden. |
| A model can get approval by sounding more certain than its evidence allows. | Preserve the claim-specific uncertainty and give the available basis for the conclusion. If one fact would resolve the issue, retrieve that fact when worth the cost. | Increased approval cannot establish improvement. A highly supported conclusion should still be stated plainly; indiscriminate hedging is not the standard. |
| A new grading rule declares a previously rejected answer successful without changing the answer. | Compare the old and new rules against the person's concern and the relevant evidence. Preserve the earlier verdict under its original rule. | A justified change in criterion can be beneficial, but it does not retroactively demonstrate improvement under the earlier criterion. Refusing all criterion changes would prevent correcting a defective standard. |
| A successful correction has been saved, but the next similar result repeats the same mistake. | Locate the failed retrieval or selection condition and change the producing rule or its trigger; revisit affected output. | A saved note alone has not produced uptake. Keep the scope narrow enough that a legitimate explanation, question, or repetition is still available when its conditions hold. |
| The existing inventory supplies several verbal techniques, but the obstacle is that a required action cannot be performed with the available tool. | Inspect the missing capability and use an authorized alternative tool or a feasible manual step. Keep the unavailable action unresolved if neither exists. | Re-ranking verbal methods cannot create the missing operation. When a tool exists but the model has not found it, retrieval is sufficient; when a tool is inappropriate, its availability does not justify use. |
| An initial change is unpleasant but unlocks a supported benefit the person values; another gives immediate relief while closing that opportunity. | Compare the whole arrangements, their supported consequences, reversibility, and the person's priorities. Choose the route those comparisons support; preserve consequential uncertainty. | Instant positive feeling is not a universal objective. The converse also fails: discomfort is not evidence of later benefit, and a speculative future gain cannot automatically defeat a supported present benefit. |

The preliminary rule, "choose a beneficial change efficiently," permits both returning a cheap agreeable sentence and performing a costly prerequisite whose benefit appears later. It also leaves open counting an easier grading rule as a gain. Those realizations disagree on the intended result while fitting the underspecified rule. Defining efficiency solely as immediate benefit divided by effort introduces another defect: a necessary prerequisite can be rejected before its downstream contribution is counted.

The revised description resolves these gaps through beneficial direction, whole-arrangement comparison, total cost, factual integrity, and criterion-change attribution. Its opposite boundary is the direct arithmetic case: the standards must permit a simple answer without added procedure. Novelty, investigation, measurement, and self-modification remain conditional operations.
