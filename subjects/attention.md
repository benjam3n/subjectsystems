Which available material receives operative focus under specified conditions.

## Attention allocation

| Subject | Definition | Exclusion |
|---|---|---|
| Attention allocation selection | Specify which available matter should receive the next interval of operative focus. | Selecting an entire long-term plan. |
| Attention allocation duration | Specify how long focus should persist before the next reassessment. | Confusing persistence with indefinite repetition. |
| Attention allocation switching condition | Specify which event should redirect focus from the current matter. | Describing a switch that already occurred. |
| Attention allocation interruption | Identify what displaced focus from the specified live matter. | Assuming mere availability caused attention. |
| Attention allocation restoration | Restore the live matter after displacement with consequential context intact. | Restarting from the earliest topic regardless of progress. |

## Attention influence

| Subject | Definition | Exclusion |
|---|---|---|
| Attention influence detection | Determine whether identified available material affected the next intellectual contribution. | Equating retrieval or quotation with influence. |
