Which available material receives operative focus under specified conditions.

## Attention allocation selection

Which available matter should receive the next interval of operative focus. Excludes: Selecting an entire long-term plan.

[Mind change selection](../systems/mind-change-selection.md)

## Attention allocation duration

How long focus should persist before the next reassessment. Excludes: Confusing persistence with indefinite repetition.

## Attention allocation switching condition

Which event should redirect focus from the current matter. Excludes: Describing a switch that already occurred.

## Attention allocation interruption

What displaced focus from the specified live matter. Excludes: Assuming mere availability caused attention.

## Attention allocation restoration

Recovery of the live matter after displacement with consequential context intact. Excludes: Restarting from the earliest topic regardless of progress.

## Attention influence detection

Whether identified available material affected the next intellectual contribution. Excludes: Equating retrieval or quotation with influence.
