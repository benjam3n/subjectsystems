# Resources

Standing: Retained root; initial development. Scope and branches below are starting proposals, not an exhaustive theory.

Available means, possible uses, allocation, constraints, and configurations that change what can be done.

- Possible uses.
- Allocation.
- Configurations.
- Constraints.

- Tradeoffs.

## Frontier

Which change in resources or their arrangement makes a previously unavailable result possible?

When does rearranging existing resources create a new capability? Which apparent limitation is actually a selection or configuration error?

## Next substantive work

Reconstruct a capability gap in terms of available means, alternative uses, constraints, and a candidate configuration change.
