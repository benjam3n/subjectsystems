Continuity with earlier material under the identity and context needed for later use.

## Memory record retention

Preservation of an identified item across a specified interval or transition. Excludes: Demonstrating that its content is true.

## Memory record retrieval

Location of an existing retained item that matches the specified retrieval target. Excludes: Reconstructing content that the retained record no longer supplies.

## Memory record reconstruction

Reconstruction of an earlier item from surviving evidence with inferred parts identified. Excludes: Presenting reconstruction as a verbatim recovered source.

## Memory record identity

Which earlier item or version a recovered record represents. Excludes: Matching a title while ignoring changed contents.

## Memory record provenance

Recovery of the source path through which the recorded material was obtained or derived. Excludes: Treating a source citation as proof of the content.

## Memory record context recovery

Recovery of the conditions needed to interpret a retained item as it was intended. Excludes: Recovering isolated text without its governing conditions.

[Content placement](../systems/content-placement.md)

## Memory record status recovery

Recovery of an earlier item's status as current, proposed, rejected, superseded, or unresolved. Excludes: Reintroducing a rejected proposal as the current decision.

[Content placement](../systems/content-placement.md)

## Memory record version distinction

The substantive differences among retained versions of the same item. Excludes: Treating every file change as a meaning change.

## Memory reuse fidelity

Whether a later use preserves the recovered item's consequential content and status. Excludes: Treating successful retrieval as proof of faithful use.

## Memory reuse trigger

Which later conditions make a retained result relevant to the current work. Excludes: Requiring every stored item to be reread on every task.

[Correction propagation](../systems/correction-propagation.md)

## Memory record availability

Which identified records are accessible to an agent through specified routes at a stated time. Excludes: A record existing elsewhere or being successfully retrieved in a particular attempt.

## Memory record source attribution

Which origin produced a remembered or stored item, including perceived, imagined, inferred, or externally supplied origins. Excludes: Determining whether its content is true; an accurately attributed report can be false.

## Memory record retrieval interference

How competing records change retrieval of a specified target under fixed cues. Excludes: Total storage capacity or loss of the target record itself.

## Memory active content maintenance

How identified content remains usable over a specified delay within an active task. Excludes: Long-term record retention or replacing the active content.

## Memory active content update

How active task content is replaced or revised following a specified input. Excludes: Maintaining unchanged content or proving the revision correct.

## Memory active content capacity

How much specified content can remain usable under stated active-task conditions. Excludes: Capacity in all possible tasks or total stored knowledge.

## Memory active content interference

How specified competing material changes the usability of active task content. Excludes: Interference only during retrieval of long-term records.

## Memory active content interference control

Which operations preserve active task content against specified competing material and under what conditions. Excludes: The occurrence of interference or a claim that a named circuit necessarily implements control.

Within [Memory active content maintenance](memory.md#memory-active-content-maintenance).

## Memory active content binding

How elements of active task content are associated into a usable structure under stated conditions. Excludes: Permanent associations in storage or a universal requirement that every active representation is bound this way.

## Memory active content external support dependence

How active-content performance changes when specified external support is available or removed. Excludes: Assuming every working-memory task must exclude all external support.

## Memory active content persistence duration

How long specified active content remains usable under stated interference and support conditions. Excludes: A fixed universal lifetime or proof that time alone causes loss.
