# Prediction

Standing: Retained root; initial development. Scope and branches below are starting proposals, not an exhaustive theory.

## Frontier

Does the prediction distinguish among plausible outcomes before the outcome is observed?

Does anticipating a response forecast behavior, select an intended contribution, or do both? Which observation separates these effects?

## Next substantive work

Record a prediction before the relevant outcome and compare its distinguishing content with what occurs, without reconstructing the prediction afterward.
