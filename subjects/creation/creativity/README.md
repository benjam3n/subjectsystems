## Frontier

What produces materially different possibilities, and what merely redescribes the same possibility?

When are two candidates genuinely different in what they make possible? Which constraint preserves useful variation and which prevents it?

## Next substantive work

Generate alternatives under two different constraints and identify which variation changes a consequential design choice.
