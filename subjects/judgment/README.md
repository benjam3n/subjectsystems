# Judgment

Standing: Retained root; initial development. Scope and branches below are starting proposals, not an exhaustive theory.

Assessment, applicable standards, verdicts, and the grounds for revising them.

## Starting hierarchy

- What is being judged.
- Applicable standards.
- Comparison.
- Evidence.
- Conflicts.
- Verdict.
- Revision.
