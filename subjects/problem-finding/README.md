# Problem finding

Standing: Retained root; initial development. Scope and branches below are starting proposals, not an exhaustive theory.

Recognizing and formulating conditions whose alteration could matter, including omissions in an existing formulation.

## Starting hierarchy

- Undesirable conditions.
- Unrealized possibilities.
- Symptoms.
- Causes.
- Framing.
- Priority.

## Frontier

Which formulation identifies something that changing would actually improve the situation?

When does a new problem description expose a different intervention? Which alleged problem disappears when its purpose or standard is reconsidered?

## Next substantive work

Reconstruct one current blockage under competing descriptions and determine which differences change the possible next work.
