Usable grasp of specified relations; a capability refinement that can overlap Intelligence rather than an exclusive alternative to it.

## Understanding content

| Subject | Definition | Exclusion |
|---|---|---|
| Understanding content specification | Specify which relations an agent must be able to use for the stated understanding claim. | Equating stored prose with usable grasp. |
| Understanding content dependence | Identify which grasped relations are required for the specified further understanding. | Treating every prerequisite document as a prerequisite understanding. |

## Understanding use

| Subject | Definition | Exclusion |
|---|---|---|
| Understanding use application | Determine whether the agent can use the identified relation to handle the specified case. | Repeating its definition without using it. |
| Understanding use explanation | Determine whether the agent can reconstruct the identified relation for a stated explanatory task. | Judging an explanatory account's structure independently of the agent's ability. |
| Understanding use transfer | Determine whether the agent can use the relation in a changed representation or setting. | Recognizing identical surface wording. |

## Understanding error

| Subject | Definition | Exclusion |
|---|---|---|
| Understanding error diagnosis | Identify which relation the agent misconstrues or fails to use in the specified case. | Merely labeling the whole response unintelligent. |

|---|---|
| Understanding use transfer | Capability use transfer |
