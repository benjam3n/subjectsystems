Usable grasp of specified relations; a capability refinement that can overlap Intelligence rather than an exclusive alternative to it.

## Understanding content specification

Which relations an agent must be able to use for the stated understanding claim. Excludes: Equating stored prose with usable grasp.

## Understanding content dependence

Which grasped relations are required for the specified further understanding. Excludes: Treating every prerequisite document as a prerequisite understanding.

## Understanding use application

Whether the agent can use the identified relation to handle the specified case. Excludes: Repeating its definition without using it.

## Understanding use explanation

Whether the agent can reconstruct the identified relation for a stated explanatory task. Excludes: Judging an explanatory account's structure independently of the agent's ability.

## Understanding use transfer

Whether the agent can use the relation in a changed representation or setting. Excludes: Recognizing identical surface wording.

Within [Capability use transfer](capability.md#capability-use-transfer).

## Understanding error diagnosis

Which relation the agent misconstrues or fails to use in the specified case. Excludes: Merely labeling the whole response unintelligent.
