# Relevance

Standing: Retained root; initial development. Scope and branches below are starting proposals, not an exhaustive theory.

The particular contribution something can make to an inquiry, activity, or purpose in context.

## Starting hierarchy

- Contribution to a question.
- Contribution to a goal.
- Indirect contribution.
- Context.
- Visibility.
- Mistaken exclusion.

## Frontier

What specific difference does considering this item make to the inquiry or activity?

What distinguishes a necessary contribution from a useful alternative? Can an item become relevant through a representation change without acquiring new content?
