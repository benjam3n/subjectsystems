# Prompting

Standing: Retained root; initial development. Scope and branches below are starting proposals, not an exhaustive theory.

How instructions and conversational conditions change the work a model performs.

## Starting hierarchy

- Interpreting a request.
- Specifying operations.
- Choosing constraints.
- Changing the model’s starting conditions.
- Continuing an interaction.

## Frontier

Which parts of the desired intellectual work can an instruction reliably determine, and which require subsequent judgment?

Which part of anticipation changes selection before an answer is written? When does an exclusion constraint generate a different contribution rather than cosmetic novelty?
