# Explanation

Standing: Retained root; initial development. Scope and branches below are starting proposals, not an exhaustive theory.

What accounts for an event, contrast, mechanism, or pattern beyond restating it.

## Starting hierarchy

- Explanatory target.
- Contrast.
- Causal structure.
- Mechanism.
- Abstraction.
- Audience.
- Competing explanations.

## Frontier

What does an explanation account for that a description or restatement leaves unresolved?

Which explanatory difference changes a prediction or intervention? When does an analogy generate a hypothesis without supplying evidence for it?

## Next substantive work

Develop competing explanations of a particular missed contribution and identify an observation on which they disagree.
