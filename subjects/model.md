Specified token, attention, position, or parameter computations in computational models.

## Model token sequence representation

How a model's input symbols are represented as an ordered token sequence under a fixed vocabulary. Excludes: Assigning meanings to every token or proving that token boundaries are semantic boundaries.

## Model token vector representation

The vector assigned to a token at a stated model location and version. Excludes: Treating a vector as a uniquely identified human concept.

## Model token probability estimation

The model's probability assignments to candidate output tokens under specified context and parameters. Excludes: Choosing a token or verifying the truth of the resulting text.

## Model token output selection

Selection of an output token from a specified model distribution under a stated decoding rule. Excludes: Estimating the distribution or establishing response quality.

## Model attention weight computation

Numerical weights from specified query and key representations under a fixed attention rule. Excludes: Human attention allocation or explanatory importance of a token.

## Model attention value aggregation

The representation obtained by combining value vectors with specified attention weights. Excludes: How the weights were chosen or whether the output is a faithful explanation.

## Model sequence position representation

How sequence position is represented for a stated model computation. Excludes: Temporal order in the represented world or semantic chronology.

## Model parameter update

The changed parameter values produced by a stated training step. Excludes: Experience-dependent change in every kind of learner or general intelligence gain.

## Model state estimation

A model's estimate or distribution over an unobserved state from specified observations and assumptions. Excludes: A claim about a future event or proof that a biological system implements the model.
