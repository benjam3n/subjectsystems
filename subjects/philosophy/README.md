# Philosophy

Standing: Retained root; initial development. Scope and branches below are starting proposals, not an exhaustive theory.

Concepts, assumptions, reasons, implications, and competing accounts of foundational or systematic questions.

## Starting hierarchy

- Concepts.
- Assumptions.
- Reasons.
- Foundations.
- Implications.
- Disagreements.
- Systematic alternatives.
