# Learning

Standing: Retained root; initial development. Scope and branches below are starting proposals, not an exhaustive theory.

Changes attributable to experience or earlier results, including their persistence and transfer.

## Starting hierarchy

- What changes.
- Experience.
- Updating.
- Transfer.
- Correction.
- Persistence.
- Learning methods.

## Frontier

Which change in later behavior is justified by this earlier result, and where does the change cease to apply?

When does recording a correction change later behavior? How far does a lesson transfer before its original conditions cease to hold?

## Next substantive work

Use a later applicable case to determine whether a specific earlier correction changes the selected operation.
