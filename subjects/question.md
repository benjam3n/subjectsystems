The distinction requested by a question, its possible resolutions, or its relation to a response.

| Subject | Definition | Exclusion |
|---|---|---|
| Question specification | Specify what a question asks about, including its requested distinction. | Choosing whether asking it is worthwhile. |
| Question identity | Determine whether two formulations request the same distinction under fixed interpretation. | Matching their wording. |
| Question presupposition | Identify what must be taken for granted for the question's requested distinction to apply. | Accepting that presupposition as true. |
| Question scope | Determine the referents, cases, or time range covered by what is asked. | Selecting the audience for the wording. |

## Question candidate

| Subject | Definition | Exclusion |
|---|---|---|
| Question candidate creation | Construct a question specification introducing a stated unresolved distinction. | Producing another wording of an already identical question. |
| Question candidate modification | Revise an identified question's requested distinction or conditions. | Changing only its typography. |
| Question candidate selection | Choose which already specified question to pursue under fixed criteria. | Constructing an answer-dependent route through several questions. |

## Question answer

| Subject | Definition | Exclusion |
|---|---|---|
| Question answer space specification | Specify what differences among possible answers the question permits. | Treating the currently listed answers as exhaustive without grounds. |
| Question answer fit | Determine whether a response addresses the question's requested distinction with its interpretation fixed. | Determining whether the response is true. |
| Question answer completeness | Identify which parts of the requested resolution a response supplies or leaves unsettled. | Asking whether the answer is exhaustive outside the question's scope. |
| Question answer presupposition correction | Determine how rejecting a false presupposition resolves the original request. | Silently answering an unrelated question. |
| Question answer equivalence | Determine whether two responses settle the same requested distinctions. | Requiring identical sentences. |
| Question answer construction | Construct a response that supplies the requested distinction with any unresolved truth claims explicit. | Assuming structural responsiveness establishes correctness. |
| Question answer revision | Change a specified response to repair an identified failure to address the fixed question. | Revising a claim solely because it is false when answer fit was already satisfied. |

## Question route

| Subject | Definition | Exclusion |
|---|---|---|
| Question route specification | Specify which next question follows from each relevant answer condition. | Changing the identity of an individual question. |
| Question route branch distinction | Determine which answer differences require different continuations. | Branching on wording that changes no next investigation. |
| Question route gap detection | Find an admissible answer for which the stated route lacks an appropriate continuation. | A missing answer to an unrelated question. |
| Question route termination condition | Specify which resolved distinctions make further traversal unnecessary for the stated purpose. | Exhausting an arbitrary number of turns. |
| Question route continuation selection | Choose the applicable continuation after a specified answer is available. | Designing the route's branch rules. |

| Subject | Containing subject |
|---|---|
| Question answer completeness | Question answer fit |
| Question route specification | Plan contingency |
