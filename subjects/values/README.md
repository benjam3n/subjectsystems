# Values

Standing: Retained root; initial development. Scope and branches below are starting proposals, not an exhaustive theory.

Worth, importance, and the grounds on which purposes or alternatives merit pursuit.

## Starting hierarchy

- Worth.
- Importance.
- Reasons for favoring.
- Conflicting commitments.
- Consequences.
- Revision.

## Frontier

What would justify a standard of worth when the candidate standards themselves disagree?

Can two conflicting standards be compared without quietly adopting one of them? Which changes in a value judgment follow from new facts and which change the standard itself?

## Next substantive work

Develop a real conflict between two purposes and identify where disagreement concerns facts, consequences, or standards of worth.
