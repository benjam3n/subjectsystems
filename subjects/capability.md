Usable ability under specified conditions; includes the qualified Intelligence and Understanding refinements below.

## Capability scope specification

The class of tasks and conditions covered by a capability claim. Excludes: Inferring unlimited ability from one performance.

## Capability scope limit

A condition under which the claimed ability is unavailable. Excludes: Equating an unattempted case with demonstrated inability.

## Capability use access

Whether the agent can bring an available means into use when the specified case requires it. Excludes: Reproducing its description without selecting it.

## Capability use blockage

A condition preventing the agent from exercising an otherwise available ability. Excludes: Assuming every failure demonstrates absence of the ability.

## Capability use transfer

Whether the ability can be exercised in a specified changed context. Excludes: Repeating an identical training example.

## Capability evidence adequacy

Which capability claim the observed performances warrant under stated sampling conditions. Excludes: Generalizing a single successful performance to all conditions.

## Capability evidence discrimination

Construction of a case that separates usable capability from memorized reproduction. Excludes: Asking for the same wording already supplied.

## Capability use intervention requirement

What an intervention must change to remove the identified capability-use blockage while preserving stated limits. Excludes: Specifying a system artifact when the intervention need not be a system.
