Usable ability under specified conditions; includes the qualified Intelligence and Understanding refinements below.

## Capability scope

| Subject | Definition | Exclusion |
|---|---|---|
| Capability scope specification | Specify the class of tasks and conditions covered by a capability claim. | Inferring unlimited ability from one performance. |
| Capability scope limit | Identify a condition under which the claimed ability is unavailable. | Equating an unattempted case with demonstrated inability. |

## Capability use

| Subject | Definition | Exclusion |
|---|---|---|
| Capability use access | Determine whether the agent can bring an available means into use when the specified case requires it. | Reproducing its description without selecting it. |
| Capability use blockage | Identify a condition preventing the agent from exercising an otherwise available ability. | Assuming every failure demonstrates absence of the ability. |
| Capability use transfer | Determine whether the ability can be exercised in a specified changed context. | Repeating an identical training example. |
| Capability use intervention requirement | Specify what an intervention must change to remove the identified capability-use blockage while preserving stated limits. | Specifying a system artifact when the intervention need not be a system. |

## Capability evidence

| Subject | Definition | Exclusion |
|---|---|---|
| Capability evidence adequacy | Determine which capability claim the observed performances warrant under stated sampling conditions. | Generalizing a single successful performance to all conditions. |
| Capability evidence discrimination | Construct a case that separates usable capability from memorized reproduction. | Asking for the same wording already supplied. |
