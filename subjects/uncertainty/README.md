# Uncertainty

Standing: Retained root; initial development. Scope and branches below are starting proposals, not an exhaustive theory.

Live alternatives, what is unknown about them, and the work that could distinguish or resolve them.

## Starting hierarchy

- Sources.
- Distinctions among possibilities.
- Representation.
- Calibration.
- Resolution.
- Decisions under uncertainty.

## Frontier

Which uncertainty is resolvable, what would resolve it, and what is the correct treatment of what remains?

When does a new distinction increase useful uncertainty? Which apparently quantitative confidence statement has grounds beyond a programmed score?

## Next substantive work

Separate unresolved meanings, missing observations, and competing accounts in a live inquiry, then perform the operation appropriate to one of them.
