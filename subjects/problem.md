A specified obstruction relative to a requirement, or a remedy's adequacy to that obstruction.

## Problem formulation

| Subject | Definition | Exclusion |
|---|---|---|
| Problem formulation creation | Specify an obstruction relative to an explicit requirement and situation. | Assuming a requested artifact is the underlying problem. |
| Problem formulation modification | Revise which obstruction is alleged while retaining the reason for the revision. | Relabeling the same obstruction. |
| Problem formulation cause | Determine what produces the specified obstruction under an explicit causal account. | Merely describing its symptoms. |

## Problem remedy

| Subject | Definition | Exclusion |
|---|---|---|
| Problem remedy creation | Construct a proposed change whose stated effect addresses the specified obstruction. | Assuming that the proposed intervention will produce its stated effect. |
| Problem remedy adequacy | Determine whether a specified effect, if obtained, would remove or reduce the stated obstruction. | Establishing that the intervention actually causes that effect. |
| Problem remedy incompleteness | Identify which necessary problem condition a proposed effect leaves unsatisfied. | Rejecting a useful partial remedy merely because it is partial. |
| Problem remedy displacement | Identify a new obstruction introduced by the proposed remedy under fixed requirements. | Calling every cost a new problem without a requirement. |
| Problem remedy selection | Choose an already specified remedy under fixed adequacy facts and decision criteria. | Developing a new remedy. |
