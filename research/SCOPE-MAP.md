# From labels to defined matters

Current names and splits are in the [subject name-change map](../subjects/scopes/NAME-CHANGES.md). The table below retains the first scope model's disposition of the original labels; its compound headings are predecessor names, not the current naming rule.

Standing: Working disposition of all 39 legacy labels. The earlier [audit](SUBJECT-AUDIT.md) identified collisions; this mapping supplies the resulting scopes. Definitions are in the [scope hierarchy](../subjects/scopes/README.md).

A row can map to several scopes because the earlier word had several senses or named a containing activity. That is not permission to put one fully specified determination in several sibling categories. The “what changed” column specifies the distinction.

## Previously rejected or reconsidered names

| Name | Current treatment |
|---|---|
| Education | Remains excluded as a standalone subject. A chosen educational project can contain definite questions about capability, experiential change, expression, and other matters without reinstating the broad category. |
| Collaboration | Remains excluded as a standalone subject. Relevant contents can include commitments, courses, and communicative uptake. |
| Evaluation | No generic root is reinstated. Standard construction and application use V2 and V3; support, answer fit, and capability each retain their own determinations. |
| Integration | No generic root is reinstated. Actual composition can require course structure, encoding compatibility, dependency reasoning, and remedy adequacy. A single unresolved interface relation needs its own definition, not automatic distribution. |
| Automation | No generic root is reinstated. Execution control, feasibility, capability, and instruction uptake are distinct matters. Autonomous execution remains an implementation question for a specified system and purpose. |
| Self-improvement | No generic root is reinstated. A system can investigate its own experiential update in B2 and a comparative change in V3. Self-reference specifies the target; it does not establish a new exclusive subject. |

## Deliberate limits

The mapping accounts for the earlier names and the identified contributions of the existing local designs. It is not a semantic classification of every passage in every source, nor a claim that these words have only the meanings retained here.

A new target can reveal a missing subject. For example, the exact accessible interaction behavior of a repository interface is not completely specified by general design relations. Its own construction scope must be defined from concrete interface requirements. Leaving this gap explicit is more accurate than saying “Design covers everything constructed” and reintroducing the overlap.

Broad programmes remain usable programmes. A philosophical investigation can coordinate particular questions about standards, knowledge, inference, and other defined matters. It can also investigate its own method in N1. Distinct scoped subjects and a composition that uses them have different jobs.
