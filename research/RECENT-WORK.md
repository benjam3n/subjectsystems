# Recent work to develop

The following register carries the conversation program into Subject Systems. It separates available techniques, conceptual distinctions, and open hypotheses. It does not claim new general empirical results or reduce the project to a fixed set of operators.

The following material comes from the conversation program. These are proposed placements of techniques and hypotheses, not claims of experimentally established general effects.

## Consequential distinctions already available for use

- A conclusion, criterion, interpretation, goal, method, confidence judgment, and choice of effort can each change. Treating all of these as changing an answer hides different downstream consequences.
- A structured prompt can change which roles the existing material plays. A conclusion can become a question; a requirement can become a temporary assumption; a method can become the object investigated.
- A list keeps alternatives available before selection. Regress can question an apparent endpoint. A temporary assumption can make a distant possibility the starting condition for further work. Their effects need not be reduced to randomness.
- A departure can be tried before the current approach has been shown wrong. The trial may expose the structure that was initially invisible.
- Finding, access, recognition of relevance, compatible representation, connection, selection, execution, retention, and later use are different possible locations of blockage. The distinctions are open and need not occur in a fixed order.
- The model's intended contribution, anticipated continuation, actual response, and the user's response are different objects. Their interaction is an investigation, not an established theory of model internals.
- A successful result can change what should be attempted next. Goal journeys should examine what success makes possible rather than repeat the same stage indefinitely.

## Evidence standing

The conversation supplies user judgments and examples of changed work. General claims about why anticipation works, model reliability, chaotic behavior, universal reduction to operations, or the superiority of a particular frame remain open. Generated hypotheses should be strong enough to make a difference and precise enough to be wrong.

The current repository contains a reconstructed [naming episode](../cases/naming-and-placement.md). It supplies a real case of evolving criteria and selection; it does not settle the broader hypotheses above.
