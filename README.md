Maximize beneficial mind change with the least unnecessary time, attention, effort, and correction, across the kinds of change relevant to the person or model and the present work.

| When | Use |
|---|---|
| A needed answer is missing. | [Knowledge acquisition](changes/knowledge.md) |
| A consequential difference is present but hard to distinguish. | [Perceptual discrimination](changes/discrimination.md) |
| The work requires carrying too many dependencies at once. | [Active memory support](changes/load.md) |
| The person wants a change in willingness, interest, or perceived effort. | [Motivation change](changes/motivation.md) |
| The desired action is understood, but a removable obstacle still prevents it. | [Action enablement](changes/action.md) |
| A correction has been acknowledged but has not changed the next applicable conduct. | [Correction uptake](changes/correction.md) |
